# AutoJs6 手机侧采集（备用机：华为 P30 + 鸿蒙 4）

> 方案 C：无障碍读屏采集。不是 hook 微信——用的是系统辅助功能接口模拟"人看屏幕"，低频、只读、个人使用。

## 一、P30 首次安装（做一次）

> ⚠️ **2026-09-14 真机验证：AutoX v7.2.3 在 P30 鸿蒙4 上跑脚本报
> `Failed resolution of: AccessibilityNodeInfoExtraRenderingInfo`（v7 引用了安卓14的类，
> 鸿蒙4底座是安卓10/11）。改装 AutoJs6 v6.7.0——同一脚本生态，API 完全兼容，minSdk 24。**
> 安装包在电脑桌面 `AutoJs6_v6.7.0_arm64.apk`（132MB，arm64）。
> 之前装过的 AutoX v7.2.3 建议卸载（两个能共存，但无障碍服务别开错对象）。

1. 装 **AutoJs6**（`AutoJs6_v6.7.0_arm64.apk`，社区活跃维护版 SuperMonster003/AutoJs6）：
   用 QQ"我的手机"或数据线（手机弹 USB 用途选**传输文件**）把 APK 传到 P30，
   文件管理里点开安装。华为拦截时允许"外部来源应用"；被"纯净模式"拦住就去
   设置 → 安全 → 纯净模式 → 退出，再装。
   ⚠️ 红线：**这台手机永远不要升级鸿蒙 NEXT/5**，升了安卓运行时没了，直接废。
2. 把两个脚本（`01_权限自检.js`、`02_公众号文章采集.js`）拷到手机
   **`/sdcard/脚本/`** 文件夹（没有就新建，名字就是"脚本"两个字）。
   打开 AutoJs6 的"文件"页就能看到。
3. 系统设置 → 辅助功能 → 无障碍 → **AutoJs6**，打开开关。
4. 设置 → 应用 → AutoJs6 → 权限 → 给**存储**权限。
5. 华为保活三件套（必做，否则后台/无障碍被系统收回），具体点法：
   ① **多任务加锁**：底部上滑停住进多任务 → AutoJs6 卡片往下拉一下 → 点出现的小锁；
   ② **启动管理手动**：设置 → 应用和服务 → 应用管理 → AutoJs6 → 应用启动管理 →
   关掉"自动管理"→ 弹窗里三个开关**全开**（自启动/关联启动/后台活动）；
   ③ **电池白名单**：设置 → 电池 → 找到 AutoJs6（或应用管理→AutoJs6→耗电详情）→
   允许后台活动/设为不允许电池优化。
6. 回 AutoJs6 点 `01_权限自检.js` → 运行，全绿即成功。

## 二、每天怎么采

1. 先跑 `01_权限自检.js`（10 秒）：提示全 OK 就往下；无障碍被华为收回了就按提示重开。
2. 打开微信确认已登录。
3. 跑 `02_公众号文章采集.js`。它会自己进微信搜索→进号主页→逐篇复制链接。期间**别碰手机**。
   > ⚠️ **2026-09-15 更新**：微信已屏蔽无障碍读树，02 的自动读列表在部分场景不稳。
   > 主力方案改为 **PC 端 ADB 引擎**：`D:\GzhHarvester\` 下双击「一键夜采.bat」
   > （PC 截屏 OCR 当眼 + adb 当手，手机只负责显示和触摸）。02 与 treewatch.js 保留：
   > treewatch（常驻抓链接）仍是引擎的取 URL 通道；02 作为离线备胎。
4. 采完的结果在 `/sdcard/ghz_outbox/*.json`，Syncthing 同步到电脑（见下），电脑端双击
   `手机文章入库.bat` 抓正文归档。

## 三、改名单

编辑脚本开头的 `ACCOUNTS`，或者在 `/sdcard/ghz_outbox/config.json` 放一份：

```json
{ "accounts": ["中南大学", "中南大学图书馆"], "max_articles": 20 }
```

## 四、卡住了怎么办

脚本卡在哪一步，都会把**屏幕上所有文字** dump 到 `/sdcard/ghz_outbox/debug/` 文件夹，
文件名里带步骤名。微信改版导致选择器失灵时，把这些文件发给维护会话即可校准，
一般只需要改一个选择器。

## 五、同步到电脑

两种任选：
- **Syncthing**（推荐，自动）：电脑共享 `D:\GzhHarvester\inbox\`，手机共享 `ghz_outbox/`，
  双向自动同步；电脑端入库脚本只认 inbox 里的 json。
- 手动：数据线/QQ 把 `/sdcard/ghz_outbox/*.json` 拷到电脑 `D:\GzhHarvester\inbox\`。
